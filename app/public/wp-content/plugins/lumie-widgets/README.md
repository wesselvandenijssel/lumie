## Releasing an update

To release an update, update the version numbers in https://plugins.mbeffect.nl/mb-widgets/metadata.php and add the zipped new version of the plugin to https://plugins.mbeffect.nl/mb-widgets/files with this naming convention: `mb-widgets-<version-number>.zip`.
